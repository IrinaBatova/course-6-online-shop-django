# Проект "course-6-online-shop-django"

## Описание:

Проект "course-6-online-shop-django" — это интернет-магазин на Django, разработанный в рамках обучения
по программе "Python-разработчик".

## Реализованный функционал

- **Главная страница (Каталог)**: отображает список доступных к покупке продуктов и расширений.
- **Страница контактов**: содержит реквизиты компании и интерактивную форму обратной связи.
- **Обработка данных формы**: данные, отправленные пользователем через форму контактов (имя, телефон, сообщение), принимаются контроллером Django и логируются в консоль разработчика.

## Стек технологий

- Python 3.13.7
- Django 6.1
- Bootstrap 5 (стили и компоненты)
- Управление зависимостями: Poetry

## Установка и запуск:

1. **Клонируйте репозиторий:**
```bash
git clone https://github.com/IrinaBatova/course-6-online-shop-django.git
```

2. **Настройте и активируйте окружение с помощью Poetry:**
```bash
poetry install
```

3. **Примените миграции базы данных:**
```bash
poetry run python manage.py migrate
```

4. **Запустите локальный сервер разработки:**
```bash
poetry run python manage.py runserver
```

После запуска проект будет доступен в браузере по адресу: [http://127.0.0.1:8000](http://127.0.0.1:8000)

Все данные о проекте находятся в файле: `pyproject.toml`
