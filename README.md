# Проект "course-6-online-shop-django"

## Описание:

Проект "course-6-online-shop-django" — это интернет-магазин на Django, разрабатываемый в рамках обучения
по программе "Python-разработчик". Проект будет дорабатываться на каждом уроке в течение всего курса.

## Установка:

1. Клонируйте репозиторий:

`https://github.com/IrinaBatova/course-6-online-shop-django.git`

2. Все данные о проекте находятся в файле:

`pyproject.toml`

3. Настройте и активируйте окружение с помощью Poetry:

```bash
poetry install
```

## Использование:

1. Запустите локальный сервер разработки:

```bash
poetry run python manage.py runserver
```

2. Откройте сайт в браузере по адресу: http://127.0.0

## Лицензия:

Не требуется
